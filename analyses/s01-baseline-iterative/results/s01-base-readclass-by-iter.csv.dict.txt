analyses/lib/compare_bams.py, concatenated (216 inputs). One row per input (condition).

Column definitions (from compare_bams.py):

Read-mapping accuracy: bwa placement vs mason truth (reference coords).
Reads matched by (fragment id, mate); tolerance = 150 bp; contigs compared by name.
True span of each read: [oP, oP + read length) on its haplotype (mason -oa tags oH, oP), mapped
back to the reference (haplotypes rebuilt from the mason-format truth VCF). Placement is judged
against where an aligner would lay the read down unclipped: the start of the best alignment of
its leftmost 30 bases on its haplotype (bwa mem scores, start within 3 bp of oP), which moves it
1-3 bp only when a sequencing indel sits among those bases (~0.02% of reads); a read that then
begins inside an insertion is placed at its first reference base minus its leading inserted
bases. Tables made before 2026-10-27 took the true start/end from the truth BAM's POS/CIGAR
(off for ~1% of reads SNP-only, ~30% in s02); tables made at commit 8762eab (also 2026-10-27)
placed every read at oP.

region         : reference region / chromosome label
coverage       : simulated fold coverage
divergence     : simulated fixed divergence (D) label
heterozygosity : simulated heterozygosity (H) label
seed           : replicate random seed
caller         : variant caller whose consensus this iteration mapped to
iteration      : pseudo-it iteration (1 = single-shot map to the reference)
total_reads    : primary reads compared (sum of the placement classes)
exact          : true START (delta = 0) AND reference footprint matches truth
                 (lifted END within 10 bp), fully aligned, NO soft-clip
shifted        : correct locus, whole read START moved 1-150 bp, no soft-clip
clipped        : correct locus (<=150 bp) but soft-clipped (alt-bearing ends dropped);
                 includes 3'-clipped reads that sit at the exact start position
span_off       : correct START but reference footprint wrong by > 10 bp -- the read
                 spans the wrong indel structure (only distinguishable with --chain)
mismapped      : same contig but > 150 bp from the true position
diff_chr       : mapped to a different contig than truth
unmapped       : present in truth but unmapped by bwa
missing        : present in truth but absent from the mapped BAM (expected 0)
*_prop         : each count as a proportion of total_reads

Header: region,coverage,divergence,heterozygosity,seed,caller,iteration,total_reads,exact,shifted,clipped,span_off,mismapped,diff_chr,unmapped,missing,exact_prop,shifted_prop,clipped_prop,span_off_prop,mismapped_prop,diff_chr_prop,unmapped_prop,missing_prop
