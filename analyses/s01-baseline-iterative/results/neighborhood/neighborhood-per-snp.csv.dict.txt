Query sites: the SNPs sampled in the --pile per-SNP pileup CSVs (template analyses/s01-baseline-iterative/results/vrf-pileup/vrf-pileup-{C}-{D}.csv);
             their per-iteration 'recovered' flags come from that file.
Neighbours : OTHER true hom-div (GT 1|1) variants within +/-200 bp of the query SNP p,
             from the truth VCF (template data/s01-baseline-iterative/sim/30X/19/{D}/0.005/42/mm39-truth.norm.vcf.gz). A record is a SNP when REF and ALT are
             both 1 bp, otherwise an indel.
Recovered  : per-iteration recovered VCF (template data/s01-baseline-iterative/iter/{C}/30X/19/{D}/0.005/42/iter{k}/mm39_recovered.vcf.gz), i.e. the variants
             already baked into the consensus at that iteration.
Unrecovered: a neighbour truth variant whose position is NOT in the recovered set
             (set membership, so false-positive recovered calls cannot lower the count).
All coordinates are reference coordinates.

One row per (caller, divergence, query SNP, iteration).

Fields:
  caller                 : variant caller (gatk | bcftools | freebayes)
  divergence             : simulated hom-div divergence D
  snp_pos                : 1-based reference position of the query SNP p
  iteration              : mapping iteration (1 = single-shot)
  n_neighbor_truth       : neighbour true hom-div SNPs in [p-W, p+W], excluding p
  n_unrecovered          : of those, NOT yet recovered at this iteration
  n_neighbor_truth_indel : neighbour true hom-div indels in the window
  n_unrecovered_indel    : of those, NOT yet recovered at this iteration. Indel
                           recovery is by POSITION match of the normalized truth vs
                           recovered indels, so it slightly understates recovery.
