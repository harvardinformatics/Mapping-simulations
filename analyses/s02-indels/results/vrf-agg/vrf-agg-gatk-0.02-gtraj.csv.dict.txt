Sites      : homozygous divergent (1|1) biallelic truth SNPs; every covering read truly carries alt; recovered = (position, alt) present in the iteration's recovered VCF.
Sampling   : all truth SNPs on the region (--sample 0).
Read truth : mason -oa truth BAM (true start/end + oH haplotype per read); reads are
             assigned to every SNP their TRUE span covers.
Placement  : exact = mapped start == true start; shifted = 0 < |delta| <= 150 bp;
             mismapped = |delta| > 150 bp; diff_chr = other contig (or true start in a
             chain gap); unmapped. For s02 iter > 1 the true start is point-lifted to
             the consensus with that iteration's ref2cons chain (4th --iter field).

One row per distinct trajectory of (call status, f_alt bin) across the iterations;
the table is the aggregated input to the G (joint-state flow) plots.

Fields:
  divergence, caller : condition labels (as passed on the command line)
  s<k>               : call status at iteration k -- called | not_called
  fb<k>              : f_alt bin at iteration k, f_alt = (alt reads aligned at the
                       SNP, exact or shifted placement) / (reads truly carrying alt);
                       bins 0.0-0.2 ... 0.8-1.0 (upper edge inclusive in the top bin),
                       or 'nocov' when no read truly carries alt
  n_snps             : number of SNPs that followed this trajectory
