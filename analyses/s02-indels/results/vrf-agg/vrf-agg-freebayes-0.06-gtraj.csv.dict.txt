Sites      : homozygous divergent (1|1) biallelic truth SNPs; every covering read truly carries alt; recovered = (position, alt) present in the iteration's recovered VCF.
Sampling   : all truth SNPs on the region (--sample 0).
Read truth : mason -oa truth BAM: oH haplotype + oP haplotype position per read; the true
             reference span is [oP, oP + read length) on that haplotype, mapped back to
             the reference (truth_haplotypes.py, haplotypes rebuilt from --mason-vcf);
             each read is PLACED where an aligner would lay it unclipped: the start of
             the best alignment of its leftmost 30 bases on its haplotype (bwa mem
             scores; moves 1-3 bp off oP only for a sequencing indel among those bases,
             ~0.02% of reads; since commit efa152b, 2026-10-27), minus any inserted
             bases it starts on;
             reads are assigned to every SNP their TRUE span covers.
Placement  : exact = mapped start == true start; shifted = 0 < |delta| <= 150 bp;
             mismapped = |delta| > 150 bp; diff_chr = other contig (or true start in a
             chain gap); unmapped. For s02 iter > 1 the true start is point-lifted to
             the consensus with that iteration's ref2cons chain (4th --iter field).

One row per distinct trajectory of (call status, f_alt bin) across the iterations;
