Combined het-site allele balance summary: the one-row-per-condition summary CSVs written by
analyses/lib/allele_balance.py, concatenated. One row per input (condition).

Column definitions (from allele_balance.py):

Reference-allele bias at true heterozygous SNP sites, from the pileup.
RAF = ref_reads/(ref_reads+alt_reads); truth = 0.5, reference bias => RAF > 0.5.
MAPQ >= --min-mapq (default 20), base quality >= --min-baseq (default 13); iter>1 positions lifted via --chain.

region,coverage,divergence,heterozygosity,seed : simulation condition
caller          : variant caller whose consensus this iteration mapped to
iteration       : mapping iteration (1 = single-shot map to the reference)
n_het           : het SNP sites in the truth
n_covered       : het sites with >=1 informative (ref or alt) read (RAF computed)
n_nocov         : het sites with 0 informative reads (fully uncovered)
lift_fail       : het positions that did not lift (chain gap); 0 without --chain
mean_depth      : mean informative depth at covered het sites
mean_raf        : mean reference-allele fraction (0.5 = unbiased, >0.5 = ref bias)
frac_ref_biased : fraction of covered het sites with RAF > 0.5
frac_alt_dropout: fraction of covered het sites with alt fraction < --dropout-alt-frac (default 0.2) (near-lost)
raf_b0..raf_b9  : histogram of RAF over covered sites, bins [0,0.1),...,[0.9,1.0]
