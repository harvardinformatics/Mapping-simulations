Sites      : HETEROZYGOUS (phased 0|1 / 1|0) biallelic truth SNPs; true-alt reads are those from the alt-carrying haplotype (mason oH tag); recovered = called correctly AS A HET in the per-iteration caller VCF.
Sampling   : all truth SNPs on the region (--sample 0).
Read truth : mason -oa truth BAM (true start/end + oH haplotype per read); reads are
             assigned to every SNP their TRUE span covers.
Placement  : exact = mapped start == true start; shifted = 0 < |delta| <= 150 bp;
             mismapped = |delta| > 150 bp; diff_chr = other contig (or true start in a
             chain gap); unmapped. For s02 iter > 1 the true start is point-lifted to
             the consensus with that iteration's ref2cons chain (4th --iter field).

Read-fate composition at the SNP position, SUMMED over all SNPs, per (iteration,
call status). Counts are read-SNP pairs (a read covering 2 SNPs counts twice).

Fields:
  divergence, caller : condition labels
  iteration          : mapping iteration (1 = single-shot)
  status             : called | not_called at that iteration
  alt_at_p           : reads at the locus (exact/shifted) presenting the alt base at p
  ref_at_p           : ... presenting the reference base at p
  err_at_p           : ... presenting another base (sequencing error)
  clipped            : at the locus but soft-clipped over p
  deleted            : at the locus but p falls in a deletion of the alignment
  mapped_elsewhere   : mismapped (> 150 bp from the true start) or on another contig
  unmapped           : unmapped reads
  n_reads            : all reads truly covering the SNPs (sum of the above)
