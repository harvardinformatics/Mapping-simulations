Column definitions (from compare_vcfs.py):

Variant-calling accuracy vs controlled truth (SNPs + indels), normalized.
Divergence sites are hom-alt (1|1); het sites are 0|1. A called variant
matches a truth site by (POS, REF, ALT) after bcftools normalization.

region,coverage,divergence,heterozygosity,seed : simulation condition
caller           : variant caller (gatk | bcftools | freebayes)
iteration        : mapping iteration (1 = single-shot; 2..N = iterative)
n_truth_div       : number of truth SNP divergence (1|1) sites
div_tp            : SNP divergence called hom-alt, matching allele (recovered)
div_het           : SNP divergence called heterozygous
div_ref_or_absent : SNP divergence called hom-ref OR not called  <-- reference bias
div_other         : SNP divergence hom-alt wrong allele / edge case
n_truth_het       : number of truth SNP heterozygous (0|1) sites
het_tp/het_hom_alt/het_ref_or_absent/het_other : SNP het site call outcome
fp                : called SNP variants not matching any truth site (false positives)
n_called_snp      : total confident SNP variant calls
n_truth_indel_div : number of truth indel divergence (1|1) sites
indel_div_tp      : indel divergence recovered (hom-alt, matching REF/ALT)
indel_div_ref_or_absent : indel divergence called hom-ref OR not called
indel_div_other   : indel divergence other genotype (e.g. called het)
n_truth_indel_het : number of truth indel heterozygous (0|1) sites
indel_het_tp/indel_het_ref_or_absent/indel_het_other : indel het site outcome
fp_indel          : called indel variants not matching any truth site
n_called_indel    : total confident indel variant calls
